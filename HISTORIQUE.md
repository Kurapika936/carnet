# Historique des versions de Word Up

Pour revenir à une version : écrire à Claude **« Rollback N »** (ex. « Rollback 30 »).

| Version | Date | Ce qui a changé |
|---|---|---|
| v2–v4 | 3 oct. | Premières versions : carnet, révision, sauvegarde ; traduction DeepL via le relais Cloudflare |
| v5 | 4 oct. | Un seul bouton 🇫🇷➡️🇬🇧 pour inverser le sens de traduction |
| v6 | 4 oct. | Bouton de sens centré |
| v7 | 4 oct. | L'app installée se met à jour toute seule |
| v8 | 4 oct. | Traduction automatique, option « Ma propre traduction » |
| v9 | 4 oct. | « Traduire » d'abord, puis « Ajouter au carnet » |
| v10 | 4 oct. | Onglet 🌐 Traduire ; Réviser propose 📋 Liste ou 🃏 Flashcards |
| v11 | 4 oct. | Liste / Flashcards sur toute la largeur |
| v12 | 4 oct. | Flashcards : glisser à droite (je savais) ou à gauche (à revoir) |
| v13 | 4 oct. | La page ne défile plus pendant un glissement de carte |
| v14 | 4 oct. | Liste : mot et traduction sur une ligne ; date retirée |
| v15 | 4 oct. | Filtres Tout / À revoir / Acquis sur toute la largeur |
| v16 | 4 oct. | Tous les groupes de boutons en pleine largeur |
| v17 | 4 oct. | L'app s'appelle Word Up |
| v18 | 4 oct. | Nouveau logo |
| v19 | 4 oct. | Logo : contournement du cache de Safari |
| v20 | 4 oct. | Exemples gris retirés des champs |
| v21 | 4 oct. | Liste : l'ordre des termes suit le sens de traduction |
| v22 | 4 oct. | Bouton 🔄 pour retraduire avec un contexte |
| v24 | 4 oct. | Bouton 📋 « Coller et traduire » avec détection de la langue |
| v25 | 4 oct. | Sous-titre retiré sous le nom de l'app |
| v26 | 4 oct. | Phrase d'aide retirée sous Apparence |
| v28 | 4 oct. | Synchronisation iPhone ⇄ PC ; affichage PC |
| v29 | 5 oct. | Traduction par Claude : exemple, note d'usage, variantes ; DeepL en secours |
| v30 | 5 oct. | Bouton ✕ pour tout effacer dans le champ |
| v31 | 13 oct. | Dossiers : choix au moment d'ajouter, suggestion par Claude, filtre en Liste et Flashcards, gestion dans les Réglages, synchronisés |
| v32 | 13 oct. | Coller dans le champ vide (appui long → Coller) traduit directement, sans la fenêtre « Allow Paste » |
| v33 | 20 oct. | Ranger les mots : bouton dossier sur chaque mot, glisser-déposer (appui long ou souris), sélection multiple |

(Les numéros manquants, comme v23 et v27, étaient des étapes intermédiaires jamais publiées.)
